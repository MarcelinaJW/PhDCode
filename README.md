# PhDCode
**Overview**
This repository contains code for the analysis of SuStain and RT-QuIC seeding data. This repository also contains code for ImageJ/FIJI macros.

**Chapter 4** - OrdinalSuStainMW.py used for whole brain progression
**Chapter 4** - hippOrdinalSuStainMW.py used for hippocampus progression
**Chapter 6** - Averaging Curves.py used to make figures with averaged RT-QuIC curves
**Chapter 6** - Kmeansclusteringseeding.py used to make find clusters in seeding data

**Whole thesis**
Fiji_olympus_BFsave.ijm - Save brightfield image taken on olympus BX63
Fiji_olympus_BFthresholdNEW.ijm - Set threshold for IHC image and measure % area
Fiji_olympus_PLAthresholdNEW.ijm - Set threshold for PLA image and measure % area
Fiji_olympus_IHCParticlesNEWkei.ijm - Set threshold for IHC image and measure particule density
Fiji_olympus_PLAParticlesNEWkei.ijm - Set threshold for PLA image and measure particule density
Fiji_olympus_saveeachannelNEW.ijm - Save immunofluorescence image taken on olympus BX63 (single and mutichannel)

**Project Aims**
Sustain- characterise progression of pathology through brain areas and identify progression variants. 
RT-QuIC seeding data - Find clusters in seeding data.
